# The waste lab

A seeded AWS account for testing and demoing CloudPilot. It plants nine waste
patterns (W1 to W9) in `ap-south-1`, creates a read-only IAM role for
CloudPilot to run under, and records the ground truth in `lab-manifest.json`,
the answer key CloudPilot is scored against.

All paths below are from the repository root. `lab-manifest.json` is
generated by `scripts/build_manifest.py` and is not committed, because it
names your AWS account and its resources.

## What gets created

| ID | Resource | Waste pattern | Created by |
|---|---|---|---|
| W1 | Two unattached 500 GB gp2 volumes | Unattached volume, plus gp2 to gp3 saving | Terraform |
| W2 | One unattached 200 GB gp3 volume | Unattached volume | Terraform |
| W3 | One Elastic IP, not associated | Idle Elastic IP | Terraform |
| W4 | Stopped t3.micro, 30 GB gp3 root | Stopped instance still paying for storage | Terraform |
| W5 | Running t3.micro, 8 GB root, no workload | Idle instance | Terraform |
| W6 | Snapshot whose source volume was deleted | Orphaned snapshot | `scripts/seed.sh` |
| W7 | AMI made from the W4 instance | AMI not used by any running instance | Terraform |
| W8 | S3 bucket with three small objects | No lifecycle rule | Terraform |
| W9 | Incomplete multipart upload in the W8 bucket | Abandoned multipart upload | `scripts/seed.sh` |

The lab plants no RDS instance and no oversized instance, so the idle RDS
and oversized instance rules are not scored by it. Their tests use
hand-built inventories.

Plus a $15 monthly budget with alerts at 50% and 100% of actual spend, and
the `cloudpilot-readonly` IAM role. Every resource is tagged
`Project=cloudpilot-waste-lab` and `WastePattern=<W id>` (`none` for the
budget and the role). Sizes and names live in `lab-spec.json`.

## Prerequisites

- AWS CLI v2, Terraform 1.6 or newer, `jq`, Python 3.9 or newer
- An AWS CLI profile named `cloudpilot-seed` with rights to create the above
- `terraform/terraform.tfvars` (gitignored), copied from
  `terraform/terraform.tfvars.example`, holding the budget email and the
  account ID. Terraform refuses to run against any other account.

## Build the lab

```sh
aws sts get-caller-identity --profile cloudpilot-seed   # check the account first

python3 scripts/fetch_prices.py     # pricing/ap-south-1.json from the Price List API
python3 scripts/estimate_cost.py    # hourly and 36-hour cost, stops above $10

scripts/tf.sh init
scripts/tf.sh plan                  # review before applying
scripts/tf.sh apply                 # budget is created first

scripts/seed.sh                     # dry run: shows what W6 and W9 will create
scripts/seed.sh --confirm

python3 scripts/build_manifest.py   # writes lab-manifest.json
python3 scripts/verify.py           # one line per pattern, plus total monthly waste
```

W5 needs time: CloudWatch has to collect several hours of near-zero CPU
before the instance looks idle, so launch the lab the evening before a demo.

## Read-only role for CloudPilot

The policy is in `docs/cloudpilot-readonly-policy.json`, and Terraform attaches
that file as it stands, so a lab built before the policy changed needs
`scripts/tf.sh apply` again to pick the change up: the idle RDS rule added
`rds:DescribeDBInstances` to it. Until then a scan with the role reports that
one call as a skipped check and still finds everything else. Add this to
`~/.aws/config`; the role has no long-lived keys of its own:

```ini
[profile cloudpilot-readonly]
role_arn = arn:aws:iam::<ACCOUNT_ID>:role/cloudpilot-readonly
source_profile = cloudpilot-seed
region = ap-south-1
```

`scripts/prove-readonly.sh` is the live demo step: it assumes the role, runs
a read that succeeds, then tries to tag the W3 Elastic IP and shows the
denial. EC2 reports an IAM denial as `UnauthorizedOperation`.

## Run CloudPilot against the lab

The CloudPilot CLI lives in `packages/cli` (see its README, including the
one-command "Run in AWS CloudShell" section and the list of every AWS API it
calls). Once built, it scans with the read-only profile and scores itself
against the answer key. With no `--region` it scans every enabled region:

```sh
cd packages/cli && npm install && npm run build && cd ../..

node packages/cli/dist/index.js scan --profile cloudpilot-readonly --region ap-south-1
node packages/cli/dist/index.js eval --profile cloudpilot-readonly --region ap-south-1 \
  --manifest lab-manifest.json
```

## From an AI editor

`cloudpilot mcp` runs the scanner as an MCP server, so Claude Code, Cursor
and other MCP clients can scan the account and query the findings through
read-only tools. See "Use it from Claude Code, Cursor or any MCP client" in
`packages/cli/README.md`.

## Demo without a network

`demo/record.sh` records the demo set against the live lab (`scan --explain`
and two `ask` questions); `demo/replay.sh` plays it back with no network
calls, behind a `REPLAY MODE` banner. See "Record and replay" in
`packages/cli/README.md`.

## Tear down

```sh
scripts/teardown.sh             # dry run: lists everything tagged for the lab
scripts/teardown.sh --confirm   # deletes it all, runs terraform destroy, sweeps again
```

## Cost

`scripts/estimate_cost.py` prints the estimate from `pricing/ap-south-1.json`.
The two 500 GB gp2 volumes are most of it. Snapshot-backed patterns (W6, W7)
are priced at the full size of the source volume, which is an upper bound:
AWS bills snapshots for stored blocks only.

## Emulator fallback

If the venue network fails, the same Terraform and scripts run against a
local Moto server. See `emulator/README.md` for what is and is not real in
that mode.

## Files

| Path | Purpose |
|---|---|
| `lab-spec.json` | Sizes, names and region, shared by Terraform and the scripts |
| `terraform/` | Budget, W1 to W5, W7, W8 and the read-only role |
| `scripts/seed.sh` | W6 and W9 |
| `scripts/fetch_prices.py`, `scripts/estimate_cost.py` | Price table and cost estimate |
| `scripts/build_manifest.py`, `scripts/verify.py` | Answer key and final check |
| `scripts/prove-readonly.sh` | Live read-only demo |
| `scripts/teardown.sh` | Removal |
| `lab-manifest.json` | Answer key: IDs, expected findings, fix commands, monthly cost (generated, gitignored) |
| `lab-state/` | Local run state (gitignored) |
